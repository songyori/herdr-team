# 들여온 데이터의 라이선스

herdr-team 플러그인의 `lib/hteam/data/` 가운데 아래 데이터는 고정한 커밋의 원본에서 형식만 바꿔 들여왔다. 저장소의 `scripts/import-palettes.py` 가 원본을 받아 다시 만든다(들여온 날 2026-11-18, 다시 돌리면 같은 파일이 나온다).

| 데이터 | 원본 | 커밋 | 라이선스 |
|---|---|---|---|
| `palettes.json` 의 `taste:` 항목 | taste-skill `skills/taste-skill/library/palettes.json` (https://github.com/Leonxlnx/taste-skill) | `f6b76575f949707b4e3c37cd86cb44b0b98643e8` | MIT |
| `palettes.json` 의 `impeccable:` 항목 | impeccable `crates/context/src/palette_data.rs` (https://github.com/pbakaus/impeccable) | `d41d9860b0094dcb68030657da63461212835aaa` | Apache-2.0 |
| `overused.json` 의 `tailwind_ramp` 와 `Tailwind` 이름의 과용 색 | tailwindcss `src/public/colors.js` (https://github.com/tailwindlabs/tailwindcss) | `4f9f603e12b51cc53b8a09c7739b8f88c8eb87eb` | MIT |

`fonts-ko.json` 은 글꼴 이름·라이선스·받는 곳만 적은 목록이고 글꼴 파일은 들여오지 않는다. `overused.json` 의 Bootstrap·iOS·Material·Anthropic 색과 과용 글꼴 이름은 조사(2026-11-16)에서 모은 값이고 들여온 데이터가 아니다.

## 바꾼 점

- taste-skill: 항목마다 `id` 앞에 `taste:` 를 붙였다. `accent`·`bg`·`ink` 의 hex 를 OKLCH 글(`oklch(L C h)`, L·C 는 소수 셋째 자리, h 는 첫째 자리)로 바꿨다. `name` 과 `note` 를 ` — ` 로 이어 `mood` 에 두었다. 다른 필드(`surface`·`muted`·`accentInk`·`fields`·`tags`·`trades`·`seenIn`)는 넣지 않았다.
- impeccable(Apache-2.0 4(b) 의 바꾼 점 알림): `SEEDS` 의 항목마다 `id` 앞에 `impeccable:` 를 붙였다. `l`·`c`·`h` 글을 그대로 `accent` 의 `oklch(l c h)` 에 넣었다. `mood` 는 그대로 두었다. `strategy` 와 `TEMPLATE` 은 넣지 않았다.
- tailwindcss: 색 계열 객체의 hex 를 나온 차례로 모으고 같은 값은 한 번만 두었다. 계열 이름이 붙은 과용 색은 그 hex 를 `Tailwind <계열>-<단계>` 이름과 함께 두었다.
