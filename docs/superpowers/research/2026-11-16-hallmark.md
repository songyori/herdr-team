## 1. 정체, 동작 방식, 라이선스, 상태

### 1.1 무엇인가
- Together AI 가 만든 "AI 티 안 나는 웹 UI" 스킬. Claude Code·Codex·Cursor·OpenCode 용. 설치는 `npx skills add nutlope/hallmark` 또는 플러그인 마켓(`.claude-plugin/`).
- 구성은 마크다운 지침(`HM/SKILL.md` 18KB + `references/` 약 225KB)과 외부 의존 없는 Node 스크립트(`sloplint.mjs` 4426줄, `sloplint-render.mjs` 1283줄, `theme.mjs` 660줄 등)다. 산출물은 자기완결 HTML+CSS 한 페이지다.
- 대상은 마케팅·랜딩 페이지가 중심이다. 앱 화면은 `flow.md` § App screens 가 별도 분기이고 ROADMAP 에도 "App screens in depth"가 아직 Next 다. 한글·CJK 대응은 없다(한글 언급은 사진 라이브러리의 서울 사진 정도).

## 4. 우선순위 제안 (사용자 불만 "UI·색 획일"에 직접 효과가 큰 순)

1. B1 색 자세 + B2 색상대 규칙 + B3 중립 틴트: design-rules §3 에 3개 항목 추가. 비용 최소, 효과 큼.

3. B5 한글 글꼴 금지·포화 목록 + 대안 표: 새 파일 1개와 §1.7 보강. 글꼴 획일 해소.
4. B4 이름 붙은 룩 금지 + B7 AI 티 항목 추가: §1 확장, `lint.py` 일부 정규식.
5. A2 + B6 프로젝트 간 톤 로그와 충돌 검사: 작은 파이썬 모듈과 테스트.

7. A6 검사 방식 태그, A7 참조 검사: 유지보수성.
