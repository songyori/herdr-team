# herdr-team 11단계(Herdr Agents 계층, hc parent) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설계 15.3 의 11번을 만든다. Herdr 앱 Agents 목록에서 프로젝트 터미널(관제, 고정 에이전트 작업 터미널, 임시 워커, 관제 탭 리뷰어, 리뷰 보기 pane)을 메인 터미널 아래 한 단계로 묶는다(hc parent). 숨은 리뷰어는 지금처럼 `--no-parent` 다. herdr-team 0.7.0 → 0.7.1, herdr-orch 0.3.0 → 0.4.0.

**Architecture:** (1) horch `worker-start --parent <터미널>`: hc 에 `--parent <T> --outlive-parent --no-notify` 로 넘기고, 그 parent 가 hc 에 없어(`not_found`·`no terminal "<T>"`) 터미널이 생기지 않았으면 같은 Dispatch·이름으로 `--no-parent` 로 한 번 더 띄운다(`parent_missing`). (2) hteam 은 메인 주소를 `run.json` 의 `main_terminal` 에 둔다. `hteam up` 이 `require_main` 뒤 판정 전에, `hteam watch` 가 watch 잠금을 잡은 뒤에 쓴다. (3) 관제(`up` 의 `hc run`)는 `require_main` 주소 아래에, 워커·리뷰어(`dispatch.launch`)와 리뷰 보기 터미널(`drive._view`)은 띄우기 직전에 읽은 `main_terminal` 아래에 든다. (4) 리뷰 보기 pane 을 앱의 `pane.split` 대신 `hc run`(herdr 라벨 + attach)으로 띄운다. 보기 pane id 는 `herdr-app ls` 로 찾고, 못 찾으면 쓸 때(배치·닫기) 다시 찾는다.

**Tech Stack:** Python 3.11+ 표준 라이브러리(argparse, json, re, subprocess, unittest). 가짜 hc(`herdr-orch/tests/fakes/hc`)와 가짜 herdr-app(`herdr-team/tests/fakes/herdr-app`).

**설계 문서:** `docs/superpowers/specs/2026-11-05-herdr-team-design.md`(이하 "설계")와 `docs/superpowers/specs/2026-11-04-herdr-orch-design.md`(이하 "horch 설계"). 11단계 범위는 설계 15.3 의 11번이다. 함께 볼 절: 설계 1장(11단계 사용자 결정 표, 확인한 것 표), 3.2(parent 표와 그 아래 줄), 3.3(`HORCH_MIN`), 3.4(`main_terminal`), 5.4·5.9.2·6.1 의 7(워커 parent), 6.5(11단계 문단, 보기 pane), 7.3(watch), 7.7(11단계: 메인 규칙 줄을 더하지 않는다), 9.3(up 의 1·3), 9.6(11단계 README), 13장(11단계 한계), 15.1(11단계 시험), 15.2(11단계 실환경), 16장. horch 설계 8장(worker-start 5 의 0.4.0 줄)과 15장(0.4.0: 부모 터미널).

## Global Constraints

- Python 3.11 이상, 표준 라이브러리만. 커밋 전에 바꾼 `.py` 와 `herdr-orch/tests/fakes/hc`·`herdr-team/tests/fakes/herdr-app` 를 `python3 -m py_compile` 로 확인한다.
- 11단계 값(그대로 쓴다):
  - hc 플래그: parent 가 있으면 `--parent <T> --outlive-parent --no-notify`, 없으면 `--no-parent --no-notify`. 둘을 함께 주지 않는다. 관제는 여기에 `--keep`, 보기 터미널은 `--keep`·`--name`·`--cwd` 없음.
  - 없는 parent: hc 오류 kind `not_found`, message `no terminal "<T>"`(hc 0.1.20). 이 문구일 때만 `--no-parent` 로 한 번 더 띄운다. horch 결과 `warnings` 에 `parent_missing`, `receipt.json` 에 `parent`(받은 값)와 `parent_fallback: {parent, error: {kind, message}}`, 결과 `parent`(실제로 쓴 값, 없으면 null).
  - horch `--parent` 형식 `[A-Za-z0-9_.:-]{1,64}`. 문구: `--parent 와 --hidden 은 같이 쓸 수 없다(pane 없는 자식은 부모의 pane·탭을 닫으면 함께 끝난다)`, `--parent 는 영문자·숫자·_·.·:·- 로 된 1–64자다(hc 주소나 이름)`, `--terminal` 과의 충돌은 지금 문구의 목록에 `--parent` 를 더한다.
  - `run.json` 키 `main_terminal`(`RACE_KEYS`·`LAUNCH_KEYS` 에 넣지 않는다). 잠금 순서는 watch 잠금 → `run.lock` 하나다.
  - hteam 경고 문구: up `메인 터미널 <메인> 이 hc 에 없어 관제를 parent 없이 띄웠다(parent_missing)`, 보기 로그 `<에이전트> 리뷰 보기: 메인 터미널 <주소> 이 hc 에 없어 parent 없이 열었다`.
- `templates/CLAUDE.section.md`·스킬·직무 문서는 바꾸지 않는다(설계 7.7 의 11단계). 메인 규칙·스킬이 메인에게 `hc kill`·`hc wait`·`hc rm` 을 시키지 않는다.
- 판별 코드(`outbox.require_main`, `roles._label_role`)는 바꾸지 않는다. 회귀 시험만 더한다(설계 1장 확인한 것 마지막 줄).
- 문서·메시지·주석은 한국어. 명령·코드 식별자·hc 의 영문 오류 문구는 원문.
- 저장소는 공개돼 있다. 커밋 전에 `git grep -n -I -P '/[U]sers/|/private/[t]mp|~[/]Workspace' -- . ':!.codex-reviews'` 가 아무것도 찾지 않아야 한다.
- 버전: Task 1 이 herdr-orch 를 `0.4.0` 으로(`herdr-orch/lib/horch/paths.py` 의 `VERSION`, `herdr-orch/.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json` 의 herdr-orch 항목)와 `HORCH_MIN` 을 `0.4.0` 으로, Task 5 가 herdr-team 을 `0.7.1` 로(`herdr-team/lib/hteam/paths.py` 의 `VERSION`, `herdr-team/.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json` 의 herdr-team 항목) 올린다. horch DB 스키마는 그대로다(v4).
- 작업 브랜치 `herdr-team-p11` 에서 한다. main 에 직접 커밋하지 않는다. 커밋은 늘 경로 지정, 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 테스트: 모듈을 `(cd herdr-orch && python3 -m unittest tests.test_a)`·`(cd herdr-team && python3 -m unittest tests.test_a tests.test_b)` 로 고른다. 전체는 저장소 루트에서 `bash herdr-orch/tests/run.sh`(약 2분), `bash herdr-team/tests/run.sh`(약 22분). 두 전체 시험을 동시에 돌리지 않는다. 기다릴 때 sleep 폴링하지 않고 백그라운드 알림을 받는다. 시험은 가짜 hc·herdr-app 만 쓰고 실제 Herdr 를 건드리지 않는다.

           cwd: str | None = None, keep: bool = False, timeout: float = 30) -> dict:
    """`hc run --bg --no-notify`(관제 9.3, 리뷰 보기 6.5). hc 의 결과 JSON 을 돌려준다.

    parent 가 있으면 `--parent <parent> --outlive-parent`(Herdr Agents 목록에서 메인 아래에 들고, 메인 Claude·셸이 끝나거나
    hc kill 돼도 산다), 없으면 `--no-parent`(설계 3.2 11단계). `--no-notify` 는 늘 준다(메인 입력란에 알림을 넣지 않는다).
    그 parent 를 hc 가 찾지 못해 실패하면(parent_missing: 터미널이 생기지 않았다) `--no-parent` 로 한 번 더 띄우고 결과에
    parent_fallback {parent, message} 를 더한다. 다른 실패는 그대로 올린다(다시 띄우지 않는다).
    keep 은 `--keep`(관제: Herdr 재시작 등으로 잃은 프로그램을 원래 명령으로 다시 실행하지 않고 셸로 바꾼다. 같은 nonce 의
    관제가 저절로 되살아나지 않게. 터미널은 남아 원인을 볼 수 있다). name·cwd 는 줄 때만 넣는다(보기 터미널은 주지 않는다)."""

    def args_for(par: str | None) -> list[str]:
        args = ["run", "--bg", *(["--parent", par, "--outlive-parent"] if par else ["--no-parent"]), "--no-notify"]
        args += ["--keep"] if keep else []
        args += ["--name", name] if name else []
        args += ["--cwd", cwd] if cwd else []
        for key, value in labels.items():
            args += ["--label", f"{key}={value}"]
        return args

    try:
        return _hc(args_for(parent), ["--", *argv], timeout)
    except HteamError as exc:
        if not (parent and parent_missing(exc, parent)):
            raise
        out = _hc(args_for(None), ["--", *argv], timeout)
        return {**out, "parent_fallback": {"parent": parent, "message": exc.data.get("message")}}


def parent_missing(exc: HteamError, parent: str) -> bool:
    """hc run 이 그 parent 를 찾지 못해 터미널을 만들지 않았다(not_found, hc 0.1.20 의 문구 `no terminal "<parent>"`).
    herdr-orch 설계 15.3 과 같은 규칙이다. 다른 not_found 문구는 아니다."""
    return (exc.code == "hc_failed" and exc.data.get("kind") == "not_found"
            and exc.data.get("message") == f'no terminal "{parent}"')
